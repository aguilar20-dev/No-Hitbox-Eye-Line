# No Eye Line

A lightweight client-side Fabric mod for Minecraft 1.21.11 that removes the eye direction line rendered inside entity hitboxes.

---

## Features

* Removes entity eye direction lines
* Keeps normal hitboxes intact
* Client-side only
* Lightweight and minimal
* No gameplay changes
* Works with Fabric 1.21.11
* Fabric API not required

---

## Requirements

* Minecraft 1.21.11
* Fabric Loader

---
